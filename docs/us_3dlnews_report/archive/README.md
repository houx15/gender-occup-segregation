# Archive — deprecated report content

Kept for reference only; do not cite. Nothing here is produced by the current
scripts.

`old-report-tables/` — tables from the first version of the methods report
(national trend, reliability, state agreement, by-occupation / by-time state
tables, Garg Fig. 2 replication), before the report was reduced to
measurement and data statistics (commit d33e9da) and the analysis moved to
`analysis/` (scripts/us_analysis). Computed with the earlier 10-entry family
list and the older orientation (higher = more traditional in some tables).
Current equivalents: `analysis/` (Parts I–III) and `tables.md`.

`old-analysis-family-sphere-main/` — analysis outputs from when the family
domain's main text measure was the family-sphere word list (until 2026-10-06):
family-sphere maps, heatmaps and change tables, and the robustness runs
`robustness-household-text*` (household words with the old 6-word list).
Household-work words (21-entry list) are now the main family text measure;
family sphere is `analysis/robustness-family-sphere-text/`.
